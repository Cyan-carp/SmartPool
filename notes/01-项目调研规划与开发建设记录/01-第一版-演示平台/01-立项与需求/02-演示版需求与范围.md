# 演示版需求与范围

> 本页定义第一版演示平台的**角色、功能编号、做与不做、验收口径**。功能编号（FR/NFR）在此唯一分配，其它笔记只引用不复用编号。

## 一、角色与场景

| 角色 | 场景 | 关键权限 |
| --- | --- | --- |
| 救生员（值班） | 盯监控大屏，收到强告警后 30 秒内响应 | 看实时画面与告警；确认/解除告警；不能改围栏与阈值 |
| 泳池管理员 | 划分区域、调阈值、切算力档位、看报表 | 围栏、设备、调度、报表、事件导出 |
| 系统管理员 | 账号与权限、审计核查 | 用户角色、审计日志、全部数据 |
| 演示操作员 | 讲解时注入剧本、加速时钟、制造故障 | 仅演示控制台（可通过配置开关关闭） |

## 二、功能清单

### P0 · 主链路（必须，缺一不可演示）

| 编号 | 功能 | 说明 | 里程碑 |
| --- | --- | --- | --- |
| FR-01 | 登录与角色菜单 | JWT + 角色路由；三角色可见菜单不同 | M1 |
| FR-02 | 实时监控画面 | Canvas 合成泳池俯视画面，叠加检测框、`track_id`、姿态标签、风险分 | M2 |
| FR-03 | 实时数据推送 | WebSocket 推送检测帧、告警、设备状态；断线自动重连并补拉快照 | M2 |
| FR-04 | 风险判定 | 规则（头部未出水时长）+ 时序风险分，输出 `NORMAL/NOTICE/WEAK/STRONG` | M2 |
| FR-05 | 分级告警 | 三级差异化呈现（颜色/声音/置顶）；同类合并、超时升级 | M3 |
| FR-06 | 告警处置闭环 | 确认 → 处置 → 解除 / 误报标记，全程留操作人与时间 | M3 |
| FR-07 | 事件回溯 | 按时间与区域筛选，回放标记片段（画面 + 轨迹 + 风险曲线） | M3 |
| FR-08 | 电子围栏 | 画面多边形绘制、区域命名与适宜人群、越界 + 持续时长判定、豁免对象 | M4 |
| FR-09 | 手环联动 | 目标与手环配对显示；心率/血氧/静止时长异常参与判定 | M4 |
| FR-10 | 数据看板 | 人数与密度、区域热力图、行为趋势、峰谷统计 | M4 |
| FR-11 | 设备与水质 | 摄像头在线/清洁度/密封/供电；水温、浑浊度、pH 阈值与提示 | M5 |
| FR-12 | 算力调度 | 高峰/低谷档位切换，联动置信度阈值、T、步长；展示算力与延迟曲线 | M5 |
| FR-13 | 演示控制台 | 剧本注入、时钟倍速、故障注入、一键重置数据 | M6 |

### P1 · 增强（有余力再做，不阻塞演示）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| FR-14 | 事件导出 | 导出 CSV / 打印版 PDF（含截图与处置记录） |
| FR-15 | 告警通知外发 | Webhook / 飞书卡片（`stages/05-alerting`） |
| FR-16 | 夜间闯入 | 非营业时段人员进入 → 抓图 + 强告警 |
| FR-17 | 模型面板 | 模型版本、mAP、延迟分布、推理日志（数据来自占位服务） |
| FR-18 | 报表 | 日报/周报：告警数、误报率、响应时长、峰谷人流 |

### 明确不做（第一版边界）

> 以下项目**不在第一版实现**，对外材料不得表述为已支持。

- 真实视频流接入（RTSP / GB28181 / HLS 推流解码），不做 FFmpeg 转码链路。
- 真实 Mamba-YOLO 权重与训练流程；不做数据集采集、标注与增强实验。
- 真实手环、水质传感器硬件对接（协议、蓝牙、MQTT 设备接入）。
- Kafka、Spring Cloud 微服务拆分、K8S 编排、多机分布式。
- 面部识别、身份实名、跨场馆多租户、计费。
- 公网部署与等保测评。

## 三、非功能需求

| 编号 | 要求 | 演示版做法 |
| --- | --- | --- |
| NFR-01 | 告警端到端延迟 | 合成数据链路下 ≤ 1 s（前端渲染到告警卡片出现） |
| NFR-02 | 画面流畅度 | 合成画面 ≥ 25 FPS（浏览器实测） |
| NFR-03 | 并发 | 单机 ≥ 20 个观察端同时在线不崩 |
| NFR-04 | 可复现 | 一键重置后同一剧本产生可对比的结果 |
| NFR-05 | 安全 | 密码哈希存储；JWT 过期；接口按角色鉴权；不记录人脸 |
| NFR-06 | 可替换性 | 推理服务通过 `Detector` 接口接入，切换真实模型不改前端契约 |
| NFR-07 | 可观测 | 每个服务输出结构化日志；演示批次留 `run_id` |

## 四、验收口径

演示版验收按「能演、能讲、能复现」三条判定：

- **能演**：FR-01 至 FR-13 在同一台机器上一次启动、按剧本完整走通，无手动改数据库。
- **能讲**：每个界面能对应到申报书的功能条目（见 [[01-项目调研规划与开发建设记录/01-第一版-演示平台/01-立项与需求/01-申报书要点提炼]]）。
- **能复现**：清空数据后按 README 步骤重建，结果一致；截图与日志留存到 `artifacts/`。

> 演示通过 ≠ 真实环境可用。申报书中的精度、延迟、算力降幅指标不在演示验收范围内。
