# 申报书要点提炼

> 本页只做**事实摘录与结构化**，不改写原意。原文：`智慧泳池溺水实时防护系统——基于Mamba-YOLO的监测与预警研究(3).doc`（存放于上级目录）。凡属「目标」「计划」的内容，一律标注为申报书口径，不等于已实现。

## 一、研究目的（原文四条）

1. **响应体育场馆智能化**：国办发〔2025〕31 号提出 2030 年体育产业总规模超 7 万亿元、推动体育智能化数字化；《体育场馆智慧化标准体系建设指南》（国家体育总局体育信息中心，2022）明确智慧化方向。
2. **增强溺水监测**：WHO 数据 2021 年全球约 30 万人死于溺水，我国每年约 5.7 万人，未成年人占比 56%。
3. **提高生还率**：溺水 1–2 分钟内正确施救生还率可达 90% 以上，5 分钟内约 50%，超过 10 分钟脑死亡风险高。
4. **提升监测效率**：人工值守依赖职业道德、效率低且不稳定，需系统化稳定监管。

## 二、功能需求（原文）

### 水上检测系统

- 基于 Mamba-YOLO 实时预测游客状态，提醒工作人员注意危险行为。
- 危险行为概率较高时，用**手环定位 + 摄像头定位配对**确认身份并警示。
- **电子围栏**：自定义儿童池/成人池、深水区/浅水区，管理适宜人群。
- **数据加密传输**：依《个人信息保护法》，加密传输 + 访问权限限制。
- **事件回溯与导出**：检测到危险行为或围栏预警时自动标记时间点，支持按标记筛选历史记录。

### 水下检测系统

- 实时识别水下人体，输出目标位置与行为类别。
- 集成水质传感器（水温、浑浊度、pH），超标影响精度时提示清洁维护。
- 监测摄像头镜头清洁度、防水密封性、供电稳定性，故障即告警。
- 依托姿态统计「疑似溺水姿态时长」，超阈值强化预警并关联实时位置。

### 统一多任务（创新点之一）

- 区域准入管理（非适宜群体进入深水区提醒）。
- 营业外时间非工作人员进入 → 抓图上传云端 + 报警。
- 溺水检测同时做人数与密度估计，输出全池/分区拥挤度与热力图，统计峰谷时段。
- 水质超标（如浑浊度 > 5 NTU）自动提示维护。

## 三、技术架构（原文）

| 层 | 原文选型 |
| --- | --- |
| 前端 | Vue3 + TypeScript（Composition API）、Element Plus、ECharts、Axios、WebSocket（含断线重连）、Pinia |
| 后端 | SpringBoot + MyBatis-Plus + Lettuce；SpringCloud + Docker + K8S；FFmpeg + OpenCV；WebSocket；Redis；Kafka；MySQL 8.0 |
| 算法 | Mamba-YOLO（ODMamba Backbone · SS2D · ODSSBlock · LS Block · RG Block · PAFPN）、DeepSORT、Temporal Transformer |

## 四、数据集与模型（原文）

- 数据来源：Roboflow 收集 + 实地模仿溺水行为采样；少量视频用 FFmpeg 抽帧 + 片段级标注。
- 水上增强：`RandomBrightnessContrast(brightness_limit=0.2, contrast_limit=0.2, p=0.5)` 抗眩光与镜面反射。
- 水下增强：改进 FUnIE-GAN（双分支编码 + U-Net 残差 + 1×1/3×3/5×5/5×5/7×7 多尺度卷积 + PReLU + BN + CBAM），马尔可夫判别器；生成器权重 λ₁=0.7、λ₂=0.3。
- 损失与样本均衡：Slide Loss（难度自适应加权）+ RPLoss（拥挤场景排斥项），原文称 Easy/Medium/Hard 精度上涨 3–4 点。
- 时序：DeepSORT 稳定 `track_id` → 特征序列（框中心/面积/纵横比/速度/加速度/头部出水概率/动作强度/水上下域标识）→ 滑窗 T=60、步长 s=10 → Temporal Transformer 输出风险分，与规则和手环数据晚期融合。

## 五、分时域算力自适应调度（原文）

| 项 | 高峰时段 | 低谷时段 |
| --- | --- | --- |
| 架构 | 完整：ODMamba Backbone + 全层 PAFPN + ODSSBlock + LS Block + RG Block | 精简：基础层 + 2 层 PAFPN + RG Block，关闭 50% LS Block |
| 算力占比 | 100% | 65%–70%（宣称降低 30%，精度维持 88%/85% 以上） |
| 置信度阈值 | 0.7 | 0.85 |
| 滑窗 T | 30 s | 60 s |
| 特征步长 | 1×1 | 2×2 |

补充规则：延迟 > 200 ms 自动临时启用 1 个备用 LS Block；精度偏差反向微调阈值，形成闭环。

## 六、拟解决关键问题（原文）

1. **视频流时序**：秒级响应 + 溺水是连续过程 → Temporal Transformer + 滑窗推理 + 手环融合 + WebSocket 前端可视化 + 异步任务队列。
2. **模型精度**：小目标优化、补充真实样本、迁移与自监督预训练。
3. **合规**：仅提取动作与位置等非身份标识数据，不存面部；SSL 加密传输；救生员只看实时画面，管理员可查历史。

## 八、已有基础（原文）

- Mamba-YOLO 初步训练：溺水行为分数 0.9 以上；远距离小目标正常游泳分数偏低。
- 已实现：Mamba-YOLO 两分类检测（≤200 ms/帧）、分时算力手动切换（低谷降 25%）、电子围栏（误差 ≤0.5 m、判定准确率 ≥90%、10 s 越界判定、工作服颜色豁免）。
- 团队获国家级 31 项、省级 61 项奖项，专利及软著 27 项；实验室有 RTX2070 / GTX1080 / TITAN X。
