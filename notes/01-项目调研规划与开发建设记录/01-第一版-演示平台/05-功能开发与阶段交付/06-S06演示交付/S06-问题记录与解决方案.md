# S06 · 问题记录与解决方案

## 一、后端无法真的停掉推理容器

| 项 | 内容 |
| --- | --- |
| 现象 | 「推理中断」需要演示，但后端没有 Docker 控制权 |
| 原因 | 后端容器未挂载 docker socket，也不应该拥有这种权限 |
| 影响 | 无法用真实停容器的方式演示降级 |
| 解决 | 用 `LiveFeedService.pause(true)` 冻结取帧，广播 `degraded`；到时自动恢复并广播 `ok` |
| 验证 | `paused=true` 时数据延迟涨到 4s，恢复后回到 34ms |
| 状态 | 已解决（演示效果等价，且不改容器状态） |

## 二、重置后仍有几十条历史告警

| 项 | 内容 |
| --- | --- |
| 现象 | 演示前重置，告警中心仍有一堆测试告警 |
| 原因 | 重置只播种模拟世界，不清业务表 |
| 影响 | 演示画面脏，统计数据不可信 |
| 解决 | `/demo/reset` 增加 `clearAlerts` 参数，清空 `alert` / `alert_action` / `risk_event`；演示控制台默认带上 |
| 验证 | 清空 32 条告警、70 条动作、32 条风险事件，`openAlerts=0` |
| 状态 | 已解决 |

## 三、故障注入后没有残留清理

| 项 | 内容 |
| --- | --- |
| 现象 | 摄像头离线后若未到时间就重置，设备仍显示离线 |
| 原因 | 恢复依赖定时线程，重置路径没考虑 |
| 影响 | 下一场演示从异常状态开始 |
| 解决 | `reset` 调用 `faultService.clearAll()`：恢复所有摄像头、解除暂停、清空活动故障 |
| 验证 | 重置后 `openFaults=0`、摄像头 4/4 |
| 状态 | 已解决 |

## 四、八步主线无法自动判断「看板/回溯看过没」

| 项 | 内容 |
| --- | --- |
| 现象 | 有些步骤没有对应接口能判定是否完成 |
| 原因 | 纯前端行为（点进页面）没有服务端记录 |
| 影响 | 进度条不会自己走满 |
| 解决 | 可自动判定的用状态接口（剧本/告警/处置/档位），其余提供「标记完成」并跳转 |
| 验证 | 进度条随演示推进，手动步骤可补 |
| 状态 | 已接受（演示辅助工具，不追求强一致） |

## 五、告警锁存只在浏览器 localStorage

| 项 | 内容 |
| --- | --- |
| 现象 | 大屏「待确认风险」改成超阈值即锁存、人工确认才消失，但锁存列表存在 `localStorage`：换浏览器或换值守人看不到，服务端也没有确认记录 |
| 原因 | 需求（长时间留痕直到确认）被实现在前端；后端当时只有告警状态机，没有提供给大屏的「未确认列表」接口 |
| 影响 | 换设备/清缓存即丢失；无法追责；与告警中心的数据可能不一致 |
| 解决 | ① 后端新增 `GET /alerts/active`（`OPEN` 告警 + `active` 标记）；② 建单改为「同池同目标同区域只允许一条 OPEN」，风险升级只更新原单；③ 大屏改为轮询服务端 + WS `alert.created/updated` 即时刷新，确认走 `POST /alerts/{id}/ack`；④ 删除 localStorage 锁存代码 |
| 验证 | `check_latch.py`：剧本触发后 active 只有 1 条（#7，active=true），确认后 active 清空，历史状态为 `ACKED` 且时间线有 2 条动作 |
| 状态 | 已解决 |

## 六、越界告警过于频繁

| 项 | 内容 |
| --- | --- |
| 现象 | 启用服务端锁存后，正常游泳时儿童偶尔进入深水区就产生告警，面板很快被填满 |
| 原因 | 越界阈值 8 秒偏短，模拟世界里儿童位置随机漂移，会频繁触碰深水区边界 |
| 影响 | 演示噪声大，真正的溺水告警被掩盖 |
| 解决 | 儿童进入深水区阈值提高到 15 秒；`zone_intrude` 剧本仍会稳定触发，不影响演示 |
| 验证 | 复跑锁存验收：正常阶段不再出现越界告警，剧本触发后按预期产生 |
| 状态 | 已解决 |

## 七、状态自检接口聚合过多依赖

| 项 | 内容 |
| --- | --- |
| 现象 | `/demo/status` 首次调用在推理未就绪时返回 503 |
| 原因 | 直接调用 `AiClient.health()` 抛异常 |
| 影响 | 控制台首屏报错 |
| 解决 | 捕获异常后置 `aiOk=false`，其它字段照常返回，页面显示「不可用」而不是报错 |
| 验证 | 停推理后状态卡变红，页面不崩 |
| 状态 | 已解决 |
