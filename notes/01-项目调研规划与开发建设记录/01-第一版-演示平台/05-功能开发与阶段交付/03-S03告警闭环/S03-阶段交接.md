# S03 · 告警闭环 · 阶段交接

## 一、怎么造一条告警

```powershell
cd deploy\scripts
.\tunnel.ps1                                   # 保持
python deploy\scripts\trigger.py reset          # 清空风险窗口
python deploy\scripts\trigger.py drown_still    # 触发静止下沉
# 等 30–45 秒，告警中心出现强告警
python deploy\scripts\check_alerts.py           # 自动走一遍闭环
```

> 想看「弱 → 强」升级：先把时钟调到 5×（`trigger.py clock 5`）再触发，告警会先在 WEAK 建单，30 秒后自动升级。

## 四、已知坑

- 模拟源没有发布端口，**不要**从宿主机直连 8010，一律走 `/api/v1/demo/*`。
- 告警建单门槛是 WEAK，NOTICE 只留在帧里，不进告警表。
- 去重键含时间桶（60 秒），跨桶会产生新告警，这是预期行为。
- 轨迹只保留 30 分钟，回溯窗口超出会没有点。
- `alert_action` 的 `operator_id` 来自用户名反查，演示账号固定 4 个。
