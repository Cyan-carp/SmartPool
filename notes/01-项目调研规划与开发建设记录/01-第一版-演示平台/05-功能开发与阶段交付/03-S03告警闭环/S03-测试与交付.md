## 一、结论

**通过。** 告警从产生、去重、升级、处置到统计与导出全链路可用。

## 二、造警与闭环（`deploy/scripts/check_alerts.py`）

```text
[1] alerts        -> total=2 本页 2 条
[2] pick          -> id=2 level=WEAK status=OPEN track=#7
[3] ack           -> status=ACKED
[4] dispatch      -> status=DISPATCHED
[5] resolve       -> status=RESOLVED closedAt=2026-11-06T10:20:09.691
[6] re-ack        -> HTTP 409（预期 409）
[7] detail        -> actions=4 clipPoints=28 zone=None
[8] stats         -> total=2 open=0 resolved=2 falseRate=0.0% avgAck=19s
[9] export.csv    -> 3 行（含表头）
结果：通过（M3 告警闭环）
```

- 状态机：`OPEN → ACKED → DISPATCHED → RESOLVED` 正常；重复确认返回 409。
- 时间线 4 条动作（创建 / 确认 / 派单 / 解除），轨迹窗口 28 个采样点。
- 统计口径随处置实时变化，平均响应 19 秒。
- CSV 含表头与 2 条记录。
