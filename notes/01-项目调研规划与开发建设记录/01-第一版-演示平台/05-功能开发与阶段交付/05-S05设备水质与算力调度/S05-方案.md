# S05 · 设备水质与算力调度 · 方案

> M5 开工方案。执行结果见 [[S05-测试与交付]]。

## 一、范围

| 类别 | 内容 |
| --- | --- |
| 设备健康 | 摄像头清洁度/密封/供电/在线四项指标；传感器与网关指标；维护登记与指标回升 |
| 水质 | 每 10 秒采样，保留 24 小时；阈值可配（浑浊度、pH、水温）；超标联动大屏提示 |
| 算力调度 | 高峰/低谷参数模板；切档下发推理服务并持久化；指标曲线（延迟真实、算力占比模拟） |

## 二、不做的

- 不做真实硬件对接与固件命令（维护只是记录 + 指标模拟回升）。
- 不做实测算力降幅：所有占比数字标注「模拟值」。
- 不做自动排班/按营业时段的真实自动切换（`auto` 只有开关，未接定时器）。

## 三、关键口径

| 项 | 取值 |
| --- | --- |
| 水质采样 | 10 秒一次，保留 24 小时 |
| 默认阈值 | 浑浊度 ≤ 5 NTU、pH 6.8–8.0、水温 25–29 ℃ |
| 超标判定 | 任一项越界 → `exceeded` 数组返回对应键 |
| 维护类型 | `CLEAN` / `SEAL_CHECK` / `REBOOT` / `POWER_CHECK` |
| 维护后 | 清洁 → 清洁度 0.99；密封检查 → 密封 0.99；重启 → 在线 |
| 档位 | `PEAK`（0.70 / 30s / 1×1 / 100%）、`OFFPEAK`（0.85 / 60s / 2×2 / 68%） |
| 指标采样 | 10 秒一次；延迟取推理真实返回，算力占比按模板加抖动 |

## 四、验收口径

1. 设备列表含摄像头与传感器，四项指标可见；维护后对应指标回升。
2. 水质最新值带阈值与超标项；修改阈值生效；曲线有采样点。
3. 触发「水质超标」剧本后 `exceeded` 出现 `TURBIDITY`。
4. 切档后后端与推理服务档位一致，指标曲线随档位变化。
5. 所有算力相关数字在页面标注「模拟值」。
