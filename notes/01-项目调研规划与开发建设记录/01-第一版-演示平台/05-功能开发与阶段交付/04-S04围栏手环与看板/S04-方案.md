# S04 · 围栏·手环·看板 · 方案

> M4 开工方案。执行结果见 [[S04-测试与交付]]。

## 一、范围

| 类别 | 内容 |
| --- | --- |
| 围栏 CRUD | 新建 / 修改 / 删除，保存归一化多边形；删除前校验活动告警 |
| 兜底区域 | 新增 `POOL` 类型覆盖整池，解决池边目标「未分区」 |
| 越界判定 | 儿童进入深水区/禁入区 8 秒、任何目标进入禁入区 5 秒 → 弱告警；同一次越界只报一次 |
| 手环 | 列表、绑定/解绑；生理数据参与风险加权；面板展示实时心率/血氧/静止 |
| 看板 | 区域热力图（16×24 网格）、风险趋势（按分钟）、峰谷人流（小时峰值） |
| 前端 | 围栏可视化编辑器（拖拽顶点、点击加点、双击删点）、ECharts 三图 |

## 二、不做的

- 不做米制标定（仍是画面归一化坐标）。
- 不做手环固件/蓝牙对接，数据来自模拟源。
- 不做图表导出与自定义时间范围（固定 30 分钟 / 6 小时）。

## 三、关键口径

| 项 | 取值 |
| --- | --- |
| 儿童禁入区类型 | `DEEP`、`RESTRICTED` |
| 越界时长阈值 | 儿童 8 秒；禁入区 5 秒 |
| 越界告警等级 | `WEAK`（可被 30 秒规则升级为 `STRONG`） |
| 重复抑制 | 同一次进入只建一条；离开再进入才算新事件 |
| 热力网格 | 24 列 × 16 行，覆盖整池 |
| 趋势粒度 | 按分钟平均风险分 + 高风险目标数 |
| 峰谷粒度 | 按分钟统计人数，取每小时峰值 |

## 四、验收口径

1. 区域增删改可用；全池区域不可删除。
2. 触发「儿童进入深水区」后产生带区域名的越界告警，且不每分钟重复。
3. 手环可绑定/解绑，解绑后确实为空。
4. 三个统计接口都有数据，前端三张图能渲染。
