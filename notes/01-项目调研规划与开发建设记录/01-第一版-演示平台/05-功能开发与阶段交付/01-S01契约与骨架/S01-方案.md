# S01 · 契约与骨架 · 方案

> 本页是 M1 的开工方案，范围与验收口径在此冻结。执行结果见 [[S01-测试与交付]]。

## 一、范围

| 类别 | 内容 |
| --- | --- |
| 部署 | 一套 Compose 起 6 个服务；源码同步脚本；隧道访问 |
| 数据 | Flyway 建表（19 张）+ 种子（4 用户 / 1 泳池 / 4 摄像头 / 3 区域 / 4 手环 / 2 档位） |
| 后端 | 统一包络 + traceId + 全局异常 + JWT + RBAC；泳池/摄像头/区域/快照/模型信息接口；WS 推送 |
| 模拟源 | 世界状态、游客运动、姿态、手环生理、水质漂移、5 条剧本 |
| 推理 | `Detector` 抽象 + `MockDetector`；风险打分规则；`/infer` 输出帧数据 |
| 前端 | 登录、布局、9 个路由、Axios/WS 封装、监控大屏 Canvas 渲染 |

## 四、验收口径

1. `deploy/scripts/up.ps1` 能在 home-dev 上一次构建启动，6 个容器 healthy。
2. 四个演示账号可登录，菜单按角色不同。
3. `/api/v1/live/snapshot` 返回 8 个目标，带 `placeholder=true`。
4. WebSocket 握手成功并能收到 `system.notice` 与 `frames`。
5. 前端首页与静态资源 200，监控大屏能画出池体、区域与检测框。
6. 未带 token 访问业务接口返回 401。

## 五、风险与对策

| 风险 | 对策 |
| --- | --- |
| 远端无法拉取镜像 | 已通过 Docker 引擎代理解决，见 [home-dev 说明](../../../../../deploy/home-dev/README.md) |
| 构建依赖外网 | Maven/npm/pip 全走国内镜像 |
| 模型空置被误读为真实能力 | 所有输出带 `placeholder`，页面常驻「占位模型」徽标 |
| 时间口径不一致 | 容器统一 `TZ=Asia/Shanghai`，时间戳以服务端为准 |
