# S01 · 契约与骨架 · 阶段交接

> 给下一个对话/成员：M1 做到哪、怎么起、哪里容易踩坑、下一步做什么。

## 一、怎么把系统起来

```powershell
# 0. 若远端刚重启：保持桌面登录，然后拉起 Docker 引擎
ssh home-dev schtasks /run /tn SmartPoolStartDocker
Start-Sleep 60

# 1. 同步 + 构建 + 启动（首次会生成随机口令到远端 deploy/.env）
cd deploy\scripts
.\up.ps1

# 2. 另开一个窗口保持隧道
.\tunnel.ps1

# 3. 验收
python deploy\scripts\smoke.py
python deploy\scripts\check_ws.py
```

浏览器：`http://127.0.0.1:18080` → `manager / demo1234`。

## 四、已知坑

- 远端 Docker 引擎**必须**先有桌面登录会话，再 `schtasks /run`，否则 `dockerDesktopLinuxEngine` 管道不存在。
- Docker 引擎代理只认小写键名；改完要重启引擎，并确认 `docker info` 里出现 `via app settings HTTPS proxy`。
- PowerShell 脚本控制台输出保持 ASCII，否则 PS 5.1 会乱码并可能吞掉 `$` 变量。
- FastAPI 具体路径要写在 `{param}` 之前。
- `docker compose down -v` 会连 PowerSystem 的卷一起删，禁止使用。
- 本机是 UTC-8，服务端是 +08:00，看日志先对齐时区。

3. 推理侧加滑窗 T 与置信度联动，前端显示档位与延迟曲线。
4. 风险悬浮卡：头部未出水时长、静止时长、心率、血氧。
5. 补齐 M1 遗留：时间戳带时区、浏览器人工验收截图归档。

## 六、不要动的东西

- `deploy/.env`（远端私有，不入 Git）。
- `UserInitializer` 的口令升级逻辑：库里已是 BCrypt，删除会让种子口令失效。
- 契约文档与前端 `types/api.ts` 的字段名：M2 只增量，不改名。
