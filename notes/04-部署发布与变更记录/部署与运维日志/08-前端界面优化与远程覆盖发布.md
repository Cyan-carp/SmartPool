## 二、范围

`stages/04-frontend/`：`index.html`、`src/main.ts`、`src/styles/tokens.css`、`src/styles/base.css`、`src/layout/AppLayout.vue`、`src/router/index.ts`，以及 `src/views/` 下 Monitor / Replay / Zones / Wristbands / Devices / Alerts / Dashboard / Model / Demo / Login 各页；`deploy/scripts/up.ps1`、`deploy/scripts/sync.ps1`。

## 三、原因

- 原浅色白底控制台不适合值守长时间注视，青绿 / 墨绿配色不符合偏好。
- 电子围栏刻度与网格对比度不足；状态栏推理耗时位数变化导致整行移位；事件回溯视频过大、右侧空；手环生理指标堆叠不显眼。
- 风险目标列表直接取当前帧，目标恢复正常后告警即消失，与「超阈值需长时间保留排查、人工确认才可清除」的运维口径不符。
- 事件回溯页面左列下方约 450px 空白。

## 四、改动（按批次）

1. **全站视觉**：设计令牌重写为深色低刺激科技色板（底 `#0d1621`、正文 `#dfe9f3`、主色 `#43b9f5`），`html.dark` 加 Element Plus dark 变量接管，Canvas / ECharts 硬编码色值批量迁移，favicon 与 theme-color 同步。
2. **界面五项**：状态栏改 7 列 grid 加等宽数字；事件回溯视频按宽度 0.42 限高、右侧补 4 张卡；电子围栏加刻度带、网格、预览加点 + 双击确认 + 顶点删除确认；智能手环独立成 `/wristbands` 页并补 7 个演示手环；删除图标轨上方滚动条。
3. **回放控制**：按采样真实时间推进，倍速 0.5× / 1× / 2× / 4×，播完停在末尾、不循环。
4. **监控页布局**：右侧栏用绝对定位内层，高度由左侧视频卡决定，底边精确对齐；水质与运行信息移到整页下方一行 2 列重排。
5. **告警锁存**：超阈值目标入列并长期保留；恢复正常后状态单向变为「已恢复 · 待确认」，触发时姿态 / 原因固定为快照，峰值风险只增不减；`localStorage` 持久化，刷新或重开浏览器仍在；仅「确认」/「全部确认」可清除；确认过的目标需连续正常 5 秒才允许作为新事件再次告警，避免状态抖动反复弹出。实时概况改「待确认风险」与「峰值风险」。
6. **复盘明细**：事件回溯左列补帧风险色带、可跳帧采样表（当前行高亮并自动跟随）、处置时间线（`detail.actions`）、风险分布占比条，两列底边对齐。
7. **部署脚本**：`sync.ps1` / `up.ps1` 清理临时文件改用 .NET API，规避当前 PowerShell 会话中 `Remove-Item` 被外部函数覆盖导致的参数绑定失败；`up.ps1` 末尾状态回显改为 `docker ps --filter name=smartpool`。

## 六、回退

- 前端：将 `stages/04-frontend/` 源码恢复为上一版后重新执行 `deploy/scripts/up.ps1` 覆盖远程即可；无数据库迁移，数据不受影响。
- 告警锁存为浏览器本地状态，回退后可清除 `localStorage` 中 `smartpool.heldRisks.v1` / `smartpool.heldRisks.acked.v1`。

## 七、边界与待补

- 告警锁存仅在浏览器本地持久，未写服务端；若需跨设备或多值班账号共享确认状态，需后端接口与数据表配合。
- 前端页面操作变化（手环独立页、复盘明细、人工确认）尚未同步到 `notes/03-系统使用与运维手册/`，待补。
- 演示口径（模型空置、数据合成、视频合成）未改变，故未修改契约与数据模型文档。
