# 03 · M2 实时监控发布

> 批次：M2。推送链路提速 + 大屏渲染重构，覆盖 backend 与 nginx 两个镜像。

## 一、基本信息

| 项 | 值 |
| --- | --- |
| 日期 | 2026-11-06（服务端 +08:00） |
| 档位 | 兼容普通发布 |
| 目标机 | `home-dev` / `C:\home-dev\smartpool` |
| 变更镜像 | `smartpool-backend`、`smartpool-nginx`（ai / simulator 未变） |
| 方式 | `deploy/scripts/sync.ps1` → `docker compose up -d --build backend nginx` |

## 二、改动

- 推送：`LIVE_PUSH_INTERVAL_MS` 默认 100 ms（10 Hz）；新增 `LIVE_REDIS_CACHE_MS` 1000 ms 节流缓存。
- 后端：`LiveFeedService` 增加降级状态机与恢复通知；`/live/snapshot` 增加 `degraded`、`pushedFrames`、`failedFrames`。
- 前端：`MonitorView` 重写为分层渲染 + 插值 + 悬停卡 + 状态条 + 降级横幅。
- 契约：`frames` 增加 `params`；`system.notice.level` 增加 `degraded` / `ok`。
- 工具：`check_ws.py` 增加速率统计；新增 `check_degrade.py`。

## 三、验证

| 项 | 结果 |
| --- | --- |
| 推送速率 | 10.1 Hz |
| 降级（停 ai 7 s） | `degraded=true`，`dataDelay=8064 ms` |
| 恢复（起 ai 9 s） | `degraded=false`，`dataDelay=61 ms` |
| 接口回归 | 8 目标、401 鉴权、`inferMs=11.8` |
| 页面 | HTTP 200 |

## 四、回退

- 代码回退：`git` 尚未初始化，按批次快照回退；重新执行 `up.ps1` 会以当前工作区覆盖。
- 参数回退：把 `LIVE_PUSH_INTERVAL_MS` 调回 1000 即可降回 1 Hz，无需回滚镜像。
- 数据：本批次未改表结构，无迁移。
