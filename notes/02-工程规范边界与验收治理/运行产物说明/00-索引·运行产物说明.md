# 运行产物说明 · 索引

> `artifacts/` 存放 Git 忽略的运行证据；本页规定它的内部结构、命名与清理方式。

## 一、目录约定

```text
artifacts/
├── m0-空间与规范/<run_id>/
├── m1-契约与骨架/<run_id>/
├── m2-实时监控/<run_id>/
├── m3-告警闭环/<run_id>/
├── m4-围栏手环与看板/<run_id>/
├── m5-设备水质与算力调度/<run_id>/
└── m6-演示交付/<run_id>/
```

`run_id` 格式：`YYYYMMDD-HHmmss-<主题>`，例如 `20261120-143500-冷启动`。

## 二、各目录放什么

| 内容 | 位置 | 是否入库 |
| --- | --- | --- |
| 页面截图、录屏 | `artifacts/<阶段>/<run_id>/` | 否 |
| 后端/推理/前端日志片段 | 同上 | 否 |
| 导出的 CSV / PDF | 同上 | 否 |
| 数据库备份文件 | `backups/` | 否 |
| 演示用种子快照 | `artifacts/<阶段>/<run_id>/seed/` | 否 |

## 三、命名与引用

- 文件名用「步骤号-内容」，如 `03-大屏强告警.png`、`05-后端日志.txt`。
- 笔记中只写相对路径与结论，例如「证据：`artifacts/m3-告警闭环/20261215-101500-闭环验收/`」。
- 一次验收一个目录，不跨批次混放。

## 四、清理

- M 里程碑签收后可删除中间过程文件，只保留验收必需证据。
- 演示交付后保留 `m6` 全部内容，其余可清理，但清理前确认笔记里的引用同步删除。
- 删除不进回收站，确认无引用后直接删除。
