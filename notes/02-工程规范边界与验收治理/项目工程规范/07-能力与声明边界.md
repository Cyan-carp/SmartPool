# 07 · 能力与声明边界

> 防止「说出去的能力」大于「做出来的能力」。对外材料、答辩、软著文档与演示话术都受本卷约束。

## 一、能力三档

| 档位 | 定义 | 允许的说法 |
| --- | --- | --- |
| **A 已实现** | 代码可运行、有验收证据 | 「已实现」「支持」 |
| **B 已规划** | 已设计未实现，接口已预留 | 「设计中」「计划支持」 |
| **C 研究目标** | 申报书提出的算法/架构目标 | 「研究目标」「后续工作」 |

## 三、数据与隐私边界

| 项 | 规定 |
| --- | --- |
| 采集范围 | 只处理位置、姿态、区域等非身份标识数据；不做人脸识别、不做实名 |
| 存储 | 不存原始视频；只存轨迹、风险事件与片段引用 |
| 传输 | 演示环境内网 HTTP；对外演示须启用 HTTPS（自签或正式证书） |
| 访问 | 救生员看实时，管理员看历史，系统管理员管账号；全部接口按角色鉴权 |
| 审计 | 告警处置、围栏修改、参数变更、数据导出全部写 `audit_log` |
| 留存 | 轨迹 7 天，告警与审计不自动删；演示结束按需重置 |

## 四、对外表述红线

> 以下内容不得出现在 PPT、答辩稿、软著说明书、README 宣传语中：

- 任何未实测的精度、召回率、延迟、算力降幅数字。
- 「已与某某泳池合作」「已在真实场馆运行」等未经书面确认的表述。
- 「替代救生员」「全自动救援」——系统只做辅助预警。
- 「通过等保」「符合《个人信息保护法》认证」——只做了设计层面的合规约束。

## 五、演示时的边界话术

- 「当前演示使用占位模型，真实模型接入后精度以实测为准。」
- 「告警判定目前由规则加时序打分给出，深度时序模型是下一阶段工作。」
- 「画面为合成场景，用于说明交互与数据流，不代表真实场馆画面。」
