# 项目目录导航

> 现行状态只看 [[00-当前系统状态]]，本页只负责「东西放在哪」。操作命令只在各 `stages/<阶段>/README.md` 维护，本页不复制命令清单。

## 一、根目录总览

| 位置 | 用途 | 阅读时机 |
| --- | --- | --- |
| `README.md` / `AGENTS.md` / `SKILL.md` | 仓库概述、AI 协作约定、Obsidian 说明 | 首次接手 |
| `notes/00-当前系统状态.md` | 唯一事实源：阶段、口径、能力、限制 | 每次接手、交付前 |
| `notes/` | 唯一 Obsidian Vault | 设计、规范、验收、日志 |
| `stages/` | 分阶段源码，每阶段一份 README | 启动、测试、部署 |
| `deploy/` | 编排、Nginx、演示环境脚本 | 联调与打包 |
| `tools/note-governance/` | 笔记链接与元数据校验 | 笔记改动后 |
| `shared-memory/` | 跨对话协作记忆（不作验收依据） | 新对话开始 |
| `artifacts/` | Git 忽略的截图、日志、演示证据 | 复核与举证 |
| `backups/` | 备份登记（包体不入库） | 发布前后 |

| 阶段 | 职责 | 入口 |

| `stages/01-simulator` | 模拟游客、轨迹、手环、水质、摄像头状态 | [[05-代码工作区导航与链接映射/stages-01-simulator-README]] |
| `stages/02-backend` | Spring Boot 业务 API、WebSocket、告警与围栏 | [[05-代码工作区导航与链接映射/stages-02-backend-README]] |
| `stages/03-ai-service` | 推理服务外壳，Mamba-YOLO 占位与剧本注入 | [[05-代码工作区导航与链接映射/stages-03-ai-service-README]] |
| `stages/04-frontend` | Vue 3 控制台（大屏、看板、配置、演示控制台） | [[05-代码工作区导航与链接映射/stages-04-frontend-README]] |

## 三、笔记分区

| 分区 | 职责 |
| --- | --- |
| `01-项目调研规划与开发建设记录/` | 申报书提炼、需求、选型、架构、接口、里程碑交付、测试资产 |
| `02-工程规范边界与验收治理/` | 项目工程规范（8 卷）、验收清单、运行产物说明 |
| `03-系统使用与运维手册/` | 面向值班员的使用手册、面向开发者的二次开发手册 |
| `04-部署发布与变更记录/` | 部署与运维日志（编号批次，只追加不改写） |
| `05-代码工作区导航与链接映射/` | 从笔记进入代码/证据的代理页 |

## 四、文件放置规则

| 类型 | 归属位置 |
| --- | --- |
| 需求、选型、架构、接口文档 | `notes/01-…/01-第一版-演示平台/01～03-*` |
| 里程碑方案、测试与交付、问题记录、交接 | `notes/01-…/05-功能开发与阶段交付/NN-Sxx主题/` |
| 测试脚本说明、合成数据口径、资产登记 | `notes/01-…/06-测试数据与测试资产/` |
| 工程规范、验收清单、产物说明 | `notes/02-工程规范边界与验收治理/` |
| 使用与运维手册 | `notes/03-系统使用与运维手册/` |
| 部署、备份、变更批次 | `notes/04-部署发布与变更记录/部署与运维日志/` |
| 阶段源码与脚本 | `stages/NN-<英文主题>/` |
| 编排与 Nginx 配置 | `deploy/` |
| 私有配置与密钥 | 本机根 `.env`；不入 Git |
| 截图、日志、演示录像与压测原始数据 | `artifacts/<阶段>/<批次>/`（Git 忽略） |
