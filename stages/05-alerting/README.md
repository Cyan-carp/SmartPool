# 05 · 告警分发（alerting）

> 职责：把后端产生的告警按级别与订阅外发到站内、Webhook、飞书，并记录投递结果。
> 状态：**P1 功能，暂不实现**。M3 之后视进度决定是否启用。

## 边界

- 只读后端告警事件，**不改告警状态**。
- 投递失败重试 3 次后标记 `FAILED`，不阻塞主流程。
- 站内推送由后端 WebSocket 直接完成，本服务即使未启用也不影响演示。

## 启用前需要

- 后端提供告警事件查询或订阅（M3 已有 WS 广播，可复用）。
- 配置 Webhook 地址或飞书机器人 token，放 `.env`，不入 Git。
- 在 [能力与声明边界](../../notes/02-工程规范边界与验收治理/项目工程规范/07-能力与声明边界.md) 把档位从 B 改为 A。
